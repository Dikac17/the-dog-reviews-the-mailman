A dog leaves a one-star review of the mailman: he comes every day, taunts the dog through the window, and leaves — 412 barks later, he still isn't afraid. `main.py` writes that single 145-character line to `/output/entry.txt`, deterministically, with no network, no randomness, and no clock.

## Run it

```sh
python3 main.py
```
